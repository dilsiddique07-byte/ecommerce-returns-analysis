# 📦 E-Commerce Sales, Returns & Customer Analysis

An interactive data analytics solution built to analyze customer purchase patterns and identify the primary drivers behind high product returns in e-commerce.

## 🎯 Objectives
- Clean, transform, and evaluate transaction data across regions and categories.
- Identify return patterns to minimize revenue loss.
- Provide interactive drill-downs and KPI tracking for decision-makers.

## 📊 Key Insights Found
- **Clothing & Footwear** show the highest return rates (~30-35%), primarily due to sizing and fit issues.
- **Electronics & Home & Kitchen** maintain lower return rates (<12%) but represent higher ticket-size revenue.
- Regional breakdown helps identify logistics and delivery quality issues to reduce operational costs.

## 🛠️ Tech Stack & Setup
- **Core:** Python
- **Analytics & Data Handling:** Pandas, NumPy
- **Interactive UI & Visualizations:** Streamlit, Plotly
